Linux Virtualization Environment

After almost 3 months of living in Linux, I decide to create my virtual machine workflow that not VirtualBox like the old Windows time.

libvirt

to use libvirt to manage qemu/kvm, install and start this servies.

pacman -S libvirt virt-manager qemu-base iptables-nft dnsmasq dmidecode bridge-utils openbsd-netcat
systemctl start libvirtd.service && systemctl start libvirtd.service

Docker

install docker to manage container.

systemctl start docker.service && systemctl start docker.service
usermod -aG docker USER # for run docker without root permission

Vagrant

install binary.

pacman -S vagrant
# and install libvirt plugin
vagrant plugin install vagrant-libvirt

or use docker like in https://github.com/vagrant-libvirt/vagrant-libvirt#using-docker.

docker pull vagrantlibvirt/vagrant-libvirt:latest

and run vagrant by define this in profile.

vagrant(){
  docker run -i --rm \
    -e LIBVIRT_DEFAULT_URI \
    -v /var/run/libvirt/:/var/run/libvirt/ \
    -v ~/.vagrant.d:/.vagrant.d \
    -v $(realpath "${PWD}"):${PWD} \
    -w $(realpath "${PWD}") \
    --network host \
    vagrantlibvirt/vagrant-libvirt:latest \
      vagrant $@
}

Vagrantfile

Example of Vagrantfile that create multiple virtual machine.

Vagrant.require_version ">= 2.2.19", "< 2.3.0"
Vagrant.configure("2") do |config|
  config.vagrant.plugins = "vagrant-libvirt"

  # disable default
  config.vm.synced_folder ".", "/vagrant", disabled: true

  N = 3
  (1..3).each do |i|
    config.vm.define "rpi#{i}" do |node|
      node.vm.box = "debian/bullseye64"
      node.vm.hostname = "rpi#{i}.local"
      node_ip = "192.168.2.#{10+i}"
      node.vm.network :private_network, ip: node_ip, hostname: true
      # node.ssh.host = node_ip
      # node.vm.provision "file", source: "keys/.ssh/vagrant_key.pub", destination: "~/.ssh/authorized_keys"
      # node.ssh.insert_key = false
      # node.ssh.private_key_path = "keys/.ssh/vagrant_key"
      node.vm.provider :libvirt do |virt|
        if i == 1
          virt.memory = 1024
        else
          virt.memory = 512
        end
        virt.cpus = 1
      end
    end
  end
end

To use custome ssh-keypair create ssh keys in folder keys/.ssh, My key’s name is vagrant_key

ssh-keygen -C "vagrant"

and add this config to Vagrantfile.

      node.ssh.host = node_ip
      node.vm.provision "file", source: "keys/.ssh/vagrant_key.pub", destination: "~/.ssh/authorized_keys"
      node.ssh.insert_key = false
      node.ssh.private_key_path = "keys/.ssh/vagrant_key"
