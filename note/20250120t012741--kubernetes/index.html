[2024-11-27 Wed 22:32]

    • So, we should create a Service to link two applications
    • Service select pods by label
    • Communicate by using Service name as hostname

Configuration

  • Helm: Use template engine to config resource [2025-01-25 Sat 19:41]

    • 2 kind of Charts:
      • application: contain templates
      • library: contain function for developers
    • Project structure:
      • templates/
        • a directory of Kubernetes YAML file templates
        • e.g. Service, Deployment, Daemonset
        • Use Go’s text/template template engine
        • Use the values from values.yaml
      • values.yaml
        • Contain configuration values of applications
        • Reference in templates as {{ .Values.example.vars }} etc.
      • Chart.yaml
        • Contain metadata of Chart, like name, version, description
        • Reference in templates as {{ .Chart.name }} etc.

  • Kustomize: Use multiple yaml files to patch/overlay on top of one another

    • Declarative Management of Kubernetes Objects Using Kustomize | Kubernetes [2025-01-29 Wed 18:48]
    • Can generate ConfigMap and Secret from plain text files
