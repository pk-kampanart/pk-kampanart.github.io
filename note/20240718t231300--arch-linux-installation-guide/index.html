[!WARNING] GRUB has limited support for LUKS2 setup cryptsetup luksFormat --type luks1 /dev/nvme0n1p3 or convert exist encrypted drive.

cryptsetup luksConvertKey --pbkdf pbkdf2 /dev/nvme0n1p3
cryptsetup convert --type luks1 /dev/nvme0n1p3

Install Packages

  • Install Base linux:

    reflector -a 6 -n 20 —sort score -c Thailand —save /etc/pacman.d/mirrorlist

    pacman -Sy archlinux-keyring

    pacstrap -K /mnt/root base linux linux-firmware`

    arch-chroot /mnt/root

[!NOTE] for Zen kernel replace linux with linux-zen

  • Install /etc version control: > [!NOTE] > /etc/hostname file must created before this step

    pacman -S etckeeper

    cd /etc

    etckeeper init

    etckeeper commit “first commit”

  • Install essential packages

    pacman -S lvm2 btrfs-progs intel-ucode grub efibootmgr

Mkinitcpio

  • Edit mkinitcpio.conf.

    HOOKS=(base udev autodetect microcode modconf kms keyboard keymap consolefont block encrypt lvm2 filesystems fsck)

  • Regenerate initramfs

    mkinitcpio -P

GRUB

  • Install grub

    genfstab -U / > /etc/fstab grub-install —target=x86_64-efi —efi-directory=/boot —bootloader-id=GRUB —recheck grub-install —target=i386-pc —recheck /dev/nvme0n1

  • Set Kernel parameters in /etc/default/grub

    cryptdevice=UUID=:cryptlvm root=/dev/MyVolGroup/root

when <device-UUID> is LUKS partision UUID

grub-mkconfig -o /boot/grub/grub.cfg

Dm-crypt Remote unlock

# pacman -S mkinitcpio-dropbear mkinitcpio-utils mkinitcpio-netconf
  • In file /etc/mkinitcpio.conf add hooks netconf dropbear encryptssh before filesystem hook, note that encryptssh is replace encrypt.
  • Add kernel parameters in bootloader config ip=dhcp; optional netconf_timeout=
  • Reboot and ssh into it as root user.

Disk Improvement

Btrfs compression

  • Reduce write amplifications
  • Example directory to compress: /usr, /var/lib/flatpak, ~/.local/share/flatpak
  • command: chattr -R +c /dir or btrfs property set /dir commpression zstd to specify algorithm
  • force existing directory to compress right away: btrfs filesystem defragmentation -r -f -c zstd /dir
  • Defragmentation(autodefrag)
  • TRIM/discard
    • Use periodic trim (fstrim) over continuous trim (mount options discard[=async])
    • systemctl enable --now fstrim.timer: run fstrim every weeks
  • Deduplication
